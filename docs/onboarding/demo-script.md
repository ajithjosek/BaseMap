# Demo Script

**Sprint 39.5 — Onboarding / demo**

A ~10 minute guided demo for prospects or new tenants. Pre-requisite: an available tenant with the [sample data](sample-data.md) loaded.

## 1. Portfolio overview (1 min)

- Sign in, land on the **Dashboard**.
- Point out summary cards (counts, cost, risk) and the C2A Heatmap.

## 2. Applications & capabilities (2 min)

- Open **Applications** → walk 2–3 high-value rows (lifecycle, risk, owner).
- Open a detail page; note cost, capabilities, components, interfaces and compliance badges.
- Open **Capabilities** → show the tree and app coverage mapping.

## 3. Graph & data flows (1.5 min)

- Open **Graph Visualization** → show Lineage and Impact for an app.

## 4. Reporting & exports (1.5 min)

- Open **Reports / Report Builder** → run a custom report.
- Open **Exports** → generate a PDF/XLSX and mention scheduled exports.

## 5. Advanced workflows (2 min)

- Open **Tech Standards** → show standards by status and the lifecycle (approve a pending standard).
- Open **Workflows** → explain the designer; run the demonstration workflow and show the trace.
- Open **C4 Diagrams** → add a node, save a snapshot, show version restore.

## 6. Governance (1 min)

- Show **Audit Logs** and **Compliance**.
- Mention access certifications (quarterly reviews) and data retention policies.

## Close

- Ask about their biggest data-gathering bottleneck; show how import jobs + ServiceNow sync reduce manual entry.
- Offer sample data (`sample-data.md`) so they can explore on their own.

## Demo tips

- Pre-load data before going live; keep a second tab with the browser's network panel open to show API speed.
- Have the Swagger UI (`/api/docs`) handy to prove API-first extensibility.
